# Reglas de Firestore

`firestore.rules` son las reglas de la base. Se pegan a mano en la consola de Firebase:
**Firestore Database → Reglas → pegar → Publicar.**

## Probarlas en tu compu

Necesitás Node 18+ y Java 11+.

```
cd firebase
npm install
npm test
```

Corre las reglas en el emulador de Firebase (nada toca el proyecto real) y prueba quién puede leer,
escribir, invitar, sumarse, irse y sacar gente.
